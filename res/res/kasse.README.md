# public/pages/res/kasse.html

## Zweck

`public/pages/res/kasse.html` bietet ein Formular zum Erfassen der Barkasse.

## Hinweise für das Backend-Team

- Zurzeit speichert diese Seite keine Daten serverseitig.
- Wenn eine Backend-Anbindung gewünscht ist, sollte ein POST-Endpunkt und ein Formular-Submit oder Fetch ergänzt werden.

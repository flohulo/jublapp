# Funktionen der JUBL(A)PP

Die JUBL(A)PP bietet Leitenden praktische Werkzeuge für die Gruppenstunde. Wähle eine Funktion, um eine eigene Schritt-für-Schritt-Anleitung zu öffnen:

| Funktion          | Wofür ist sie gedacht?                              | Anleitung                             |
| ----------------- | --------------------------------------------------- | ------------------------------------- |
| Strike-Verwaltung | Strikes für bis zu vier Kinder erfassen             | [Strike-Verwaltung öffnen](strike.md) |
| Ereignis melden   | Unfälle, Konflikte und Sachschäden dokumentieren    | [Ereignis melden öffnen](ereignis.md) |
| Wetter            | Wetter und Prognose für die Gruppenstunde ansehen   | [Wetter öffnen](wetter.md)            |
| Links             | Notfallnummern, Jubla-Webseiten und Kontakte finden | [Links öffnen](links.md)              |
| Lager             | Padlet der Schar für das Lager ansehen              | [Lager öffnen](lager.md)              |

Informationen zur Navigation und zum Aufbau der App findest du unter [Aufbau und Bedienung](seitenaufbau.md).
